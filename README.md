# 🐍 Pet Project — Telegram/VK боты и игра на Pygame

Набор pet-проектов на Python: Telegram-бот-визитка, VK-бот для управления беседой (ролевая «армия») и аркадная игра на Pygame с таблицей рекордов.

**Цель** — практика работы с внешними API (Telegram Bot API, VK API), асинхронной обработкой событий, SQLite и графикой (Pillow, Pygame).

> ⚠️ **Безопасность:** Токены и конфиденциальные данные не хранятся в репозитории. Используется `.env` (см. `.env.example`).

---

## 📦 Структура проекта

| Папка / файл | Описание | Стек |
| :--- | :--- | :--- |
| `bot_tg/` | Telegram-бот-визитка: онлайн-меню услуг, отзывы, пересылка сообщений админу | Python, pyTelegramBotAPI |
| `vk_bot/` | VK-бот для беседы: управление должностями, варны, муты, кики, заметки, структура «армии», генерация изображений | Python, vk_api, Pillow |
| `pyth/` | Аркада «Rocket Wars»: меню, 8 уровней, режим выживания, рекорды в БД | Python, Pygame |
| `int/` | Простые числа: проверка на простоту, перебор простых чисел | Python |
| `encode/` | Кодирование строк в бинарный вид через словарь символов | Python |
| `simple_int.py` | Скрипт перебора простых чисел | Python |
| `perevod.py` | Перевод чисел в двоичную систему и обратно | Python |
| `.env.example` | Шаблон переменных окружения | — |
| `requirements.txt` | Зависимости проекта | — |

**VK-бот разбит на модули:**
- `config.py` — настройки и переменные окружения
- `db.py` — инициализация базы данных SQLite
- `image_gen.py` — генерация картинок со списком структуры
- `handlers.py` — логика команд и обработчиков
- `main.py` — точка входа и цикл longpoll
